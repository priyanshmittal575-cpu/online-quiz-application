# Online Quiz Application

Timed multiple-choice quiz web application with dynamic question rendering, score calculation, and answer review.

## Features & Overview
- Built as part of the **B.Tech 1st Year Web Designing & Full-Stack Development** project series.
- Clean, modular separation of markup, styling, client-side logic, and backend/database schemas.

## Tech Stack
- HTML5, CSS3, Vanilla JavaScript

## How to Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/priyanshmittal575-cpu/online-quiz-application.git
   cd online-quiz-application
   ```
1. Open `index.html` directly in any modern web browser (Chrome, Edge, Firefox).
